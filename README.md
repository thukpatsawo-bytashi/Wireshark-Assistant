# Wireshark Assistant

Wireshark Assistant is an AI functionality plugin that empowers users to easily interpret a packet capture, protocol behaviour in it and network events with clear and friendly explanations that do not presuppose any prerequisites.

## Features (Planned)

- Describe the selected packets in a non-technical manner
Explain actions of the TCP/IP protocol
- Describe how DNS queries and responses work.
Discuss retransmissions and typical network problems
Describe the Wireshark-traffic in colour.
- AI-assisted packet interpretation

## Tech Stack

- Lua
- Wireshark Plugin API
- Python
- FastAPI
